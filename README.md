# PANIONK

Personal portal site — AI builder workbench theme, built with Next.js 15.

**Live:** [laifuyou.com](https://laifuyou.com)

## Stack

Next.js 15 · TypeScript · Tailwind CSS v4 · Framer Motion · pnpm

## Content

Site copy and links live in `data/` as static TypeScript files. Edit those files to update projects, trails, links, and section copy.

## Dev

```bash
pnpm install
pnpm dev
```
