## Runtime assets

Use these from `/assets/generated/...` in the Next.js app.

- `public/assets/generated/hero-workbench-bg.png`
  - Hero background.
  - Keep headline, nav, HUD, CTA, coins, and interactive elements as DOM/canvas overlays.

- `public/assets/generated/identity-silhouette-panel.png`
  - Identity section atmosphere and silhouette.
  - Keep identity copy, chips, and agent loop nodes as DOM/SVG overlays.

- `public/assets/generated/paper-texture.png`
  - Reusable paper/card texture.
  - Use as subtle background overlay for project cards, notes, and route-map panels.

- `public/assets/generated/portal-glow.png`
  - Footer portal interior/glow.
  - Frame, links, CTA, footer nav, and particles should remain code-driven.

- `public/assets/generated/pixel-sprites.png`
  - Transparent sprite sheet for small interactive decorations.
  - Source chroma-key version is `pixel-sprites-key.png`.

- `public/assets/generated/panionk-runner-sprites.png`
  - Transparent 12-frame original PANIONK runner sprite sheet for the sticky HUD.
  - Source chroma-key version is `panionk-runner-sprites-source.png`.
