# ADR-0001 视觉方向：干净结构 + 字体反差

状态：已接受（2026-08-13）

## 背景

站点从「游戏化 AI 工作台」全面转向浅色简约。四个候选方向以单文件 HTML demo 形式产出（`docs/design/demos/`）：A 极简排版风、B 编辑杂志风、D 温润日系风、E 干净结构。

评审时的核心担忧是两条相互拉扯的要求：页面不能有"AI 味"，同时不能因为简洁而显得空旷单调。

## 决策

以 demo E「干净结构」为起点，但不照搬其视觉细节，叠加三项改造，最终形态见 demo F（`docs/design/demos/06-clean-structure-v2.html`）：

1. **字体反差作为唯一签名。** 规则是「散文走无衬线，数据走 mono」——中文正文用系统无衬线，Hero 字标、仓库名、star 数、日期用自托管的 IBM Plex Mono 拉丁子集。不再增加其他装饰性记忆元素。
2. **去模板化硬约束。** 去掉 `01 / PROJECTS` 编号与全大写英文 eyebrow，换掉 Tailwind 默认蓝 `#2563eb`，取消中英镜像文案。
3. **用真实元信息制造密度。** 卡片底部补 star 数、主语言、最近更新月份。密度来自信息而非装饰。

### 评审后的三次修正

- **Hero 主名称改为 Panionk。** 原方案用中文名「孙小帅」并把三个汉字拆开铺满整行，实测不好看：汉字数量少、字面宽，铺开后间距失控。改用本人在英文环境使用的名称 Panionk，它落在 mono 字体上，字标本身就成了字体反差的展示位；中文名退到副行与导航。字标不铺满、不夸张放大，收在 58px。
- **首页不再列文章。** 博客已经有入口，首页重复列出标题没有价值。写作足迹只保留平台入口卡片，RSS 抓取一并取消。
- **列表条目改为横向卡片。** 原方案是竖排三行条目，改为横向卡片栅格，桌面三列。Elsewhere 模块并入写作足迹，中间只剩两个内容模块。

第三条与最初的"用条目而非卡片"判断相反。当时的理由是条目能随内容增长而不垮，但项目收敛到三个、文章列表取消之后，条目数量已经稳定在个位数，卡片的横向栅格反而让页面更像"模块"而不是一份清单。风险是三列卡片栅格本身很接近模板长相，所以卡片必须保持无阴影、发丝边框、mono 数据行贴底对齐这几条约束。

### 落地后的第二轮修正

实现跑起来之后又砍掉了三样东西，页面收敛成 Hero + 项目 + 页脚 + 底部停靠栏：

- **去掉顶部导航和 Hero 统计行。** 页面只剩一个内容模块，导航无处可去；`杭州 · 53 个公开仓库 · 929 star` 这类数字对读者不构成决策依据，撤掉后 Hero 干净很多。
- **卡片换成圆形应用图标。** 带边框的卡片显得僵硬且占空间。改成各项目仓库里真实的应用图标（anychat 的 Tauri 图标、AmberKeeper 的 Electron 图标、ocr-app 的 apple-icon），放进统一的浅底圆形托盘，下面接项目名和一句话，去掉全部元信息。
- **平台入口收进底部固定停靠栏。** 原来的"写作足迹"模块整个撤销，博客、GitHub、掘金、X、公众号变成停靠栏里的五个图标，hover 才浮出名称。

这轮修正取消了本 ADR 原本的第 3 条决策（用真实元信息制造密度）：既然不摆数字，`lib/github.ts` 与构建时抓取一并删除，页面回到纯静态。密度改由真实的应用图标承担——图标比数字更能一眼说明"这是三个真做出来的东西"，代价是页面缩短到约一屏。版心也从 1040 收窄到 760，否则三个图标会散得太开。

## 理由

demo E 的信息架构是四个方向里最经得起内容增长的：统一区块头 + 对齐栅格条目，加十个项目也不会垮。但它的视觉细节几乎全是当前 AI 生成设计的默认答案——编号 eyebrow、hairline 分隔、默认蓝、抽象标签元信息。骨架值得留，皮值得换。

demo D 的米白配陶土是 AI 生成设计最高频的一种长相，直接淘汰。A 和 B 的排版更有性格，但 A 的巨字阶梯在内容只有个位数条目时会更空，B 的杂志目录点线在内容增长时维护成本高。

"空旷"的根因是内容太少而非留白太多：页面当时只列了 2 个项目和 3 个链接，而实际有 288 star 的 `notify-server`、50 star 的 `AmberKeeper`、6 篇标题很具体的博客文章没有上墙。所以第一优先级是补内容，而不是补装饰。

## 影响

- `app/globals.css`（31KB 游戏化样式）与 `components/panionk/PanionkSite.tsx` 需要重写。
- `public/assets/generated/` 的 8 张 PNG 作废并已删除。
- `data/` 模型调整：`identity.ts`、`links.ts`、`trail.ts` 删除；新增 `hero.ts`、`social.ts`、`icons.ts`。
- 页面保持纯静态，无数据抓取。
- 站点标题与 OG 图里的主名称改为 Panionk。
- Framer Motion 在只剩滚动淡入后可以移除。
